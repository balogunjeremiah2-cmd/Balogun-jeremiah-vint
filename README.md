# Personal Task Manager Application

* Course Title: Mobile Engineering

* Assignment: Flutter Personal Task Manager

* Framework: Flutter


##  Introduction

This application is a mobile Task Manager designed to help users track their daily activities. It was developed to demonstrate core Flutter concepts, including User Interface design, Navigation, and State Management, without relying on external backends or databases.

The app allows users to create tasks with priorities, mark them as completed, view task details, and delete tasks with a confirmation safeguard.

### Features

* Splash Screen: A welcoming startup screen that automatically navigates to the Home screen after 3 seconds.
  
* Task List: Displays a scrollable list of tasks. Each task shows its title, priority, and completion status.
  
* Add Task: A form validation screen to add new tasks with a Title, Description, and Priority level (High, Medium, Low).
  
* Task Details: A dedicated screen to view the full description and status of a specific task.
  
* State Management: Users can mark tasks as "Completed" using a checkbox, which updates the UI immediately.
  
* Delete Confirmation: Deleting a task triggers an Alert Dialog to prevent accidental deletion.
  
* User Feedback: Snackbars are displayed when a task is successfully added or deleted.
